# dark-glass-ui

A Claude Code skill for a dark, monotone, Apple-inspired UI style: liquid-glass surfaces, beveled white primary buttons, and one consistent hover/press system.

- [SKILL.md](SKILL.md) — the design language: principles, tokens, glass, interaction system, button tiers, patterns, motion, don'ts.
- [glass-ui.css](glass-ui.css) — drop-in base stylesheet (`.glass`, `.btn*`, `.field`, `.card`, `.toolbar`, `.inline-edit`, `.edit-affordance`, interaction presets).

## Install

```bash
git clone https://github.com/mvvthw/dark-glass-ui ~/.claude/skills/dark-glass-ui
```

Then in Claude Code, run `/dark-glass-ui` or ask for something "in dark glass style".

You can also use `glass-ui.css` on its own in any web project.
